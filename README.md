# BaZi Sender Bot

Telegram бот для автоматической отправки ежедневных видео и сообщений пользователям в соответствии с их часовым поясом.

## Особенности

- 🚀 **Автоматическое определение платформы** - бот автоматически определяет устройство пользователя (iOS/Android/Desktop)
- 📱 **iOS-совместимые видео** - специально оптимизированные видео для iPhone без артефактов
- 🌍 **Поддержка часовых поясов** - автоматическое определение по геолокации или городу
- 📊 **Опрос пользователей** - сбор данных о том, давно ли пользователь читает блог
- ⏰ **Планировщик сообщений** - отправка контента в 15:00 по местному времени пользователя
- 💾 **Кеширование видео** - оптимизация повторной отправки видео

## Установка

1. **Клонируйте репозиторий:**
   ```bash
   git clone <repository-url>
   cd telegram_bot_mvp_localtime
   ```

2. **Создайте виртуальное окружение:**
   ```bash
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # Linux/Mac
   source venv/bin/activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Создайте файл .env:**
   ```env
   BOT_TOKEN=your_telegram_bot_token
   ADMIN_CHAT_ID=your_admin_chat_id
   LOG_FILE=bot_errors.log
   LOG_MAX_BYTES=5242880
   LOG_BACKUPS=3
   ```

5. **Подготовьте контент:**
   - Поместите видео в папку `content/`
   - Создайте iOS-совместимые версии: `python create_ios_videos.py`
   - Поместите текстовые сообщения в папку `messages/`

## Использование

### Запуск бота:
```bash
python main.py
```

### Основные команды:
- `/start` - Начать работу с ботом
- `/settime` - Указать локацию для определения часового пояса
- `/setcity Москва` - Указать город для определения часового пояса
- `/setoffset +3` - Указать смещение от UTC вручную
- `/whoami` - Получить свой Telegram ID
- `/forceios` - Принудительно установить платформу iOS (для тестирования)

### Автоматическое определение платформы:
Бот автоматически определяет платформу пользователя по:
- Языку интерфейса (азиатские языки → iOS)
- Имени пользователя (эмодзи → iOS)
- По умолчанию → Desktop

## Создание iOS-совместимых видео

Для создания видео без артефактов на iPhone:

```bash
python create_ios_videos.py
```

Скрипт создаст папку `content/ios/` с оптимизированными видео, используя:
- H.264 кодек (нативный для iOS)
- Базовый профиль H.264 (максимальная совместимость)
- YUV420p цветовое пространство
- Отключенные B-кадры

## Логирование

Бот ведет логи ошибок в файл `bot_errors.log` с ротацией:
- Максимальный размер: 5 MB
- Количество резервных копий: 3

## Технические детали

- **Framework**: aiogram 2.25.1
- **Планировщик**: APScheduler 3.10.4
- **Временные зоны**: pytz + timezonefinder
- **Геокодинг**: geopy (Nominatim)
- **Кодирование видео**: FFmpeg с оптимизированными параметрами
